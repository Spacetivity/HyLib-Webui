# Screenshots

Place your UI screenshots in this directory.

## Recommended Screenshots

1. **main-ui.png** - Main interface showing the input and preview
2. **preview-example.png** - Example with formatted text showing different tags
3. **color-example.png** - Color tags example
4. **gradient-example.png** - Gradient example

## How to Take Screenshots

1. Start the dev server: `npm run dev`
2. Open http://localhost:5173/ in your browser
3. Take screenshots of different UI states
4. Save them in this directory (`docs/screenshots/`)
5. Use descriptive filenames (e.g., `main-ui.png`, `color-example.png`)

## Image Format

- Use PNG format for best quality
- Recommended size: 1920x1080 or similar
- Keep file sizes reasonable (< 500KB if possible)
